## Overview

Smarter Cursor extends and fixes Terraria's built-in smart cursor feature with more reliable block placement prediction, improved digging mode activation, configurable tile type preferences for mixed-material excavation, and a visual cursor highlight indicating the exact tile the smart cursor will interact with.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Smarter Cursor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Improved Prediction** | More accurate smart cursor block placement in complex terrain |
| **Digging Mode** | Enhanced smart cursor switching between place and dig modes |
| **Tile Preferences** | Configure which material types the smart cursor prioritizes |
| **Visual Highlight** | Colored tile highlight shows exactly which block smart cursor targets |
